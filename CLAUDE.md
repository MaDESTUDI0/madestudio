# 🎨 Промпт для разработки сайта MaDE

## Общее описание проекта

Ты — senior UI/UX designer и frontend-разработчик. Создаёшь современный премиальный сайт для **MaDE** — творческого ателье и школы обучения.

**Главная задача:** Сайт должен выглядеть дорого, тепло, эстетично и вызывать доверие. Целевая аудитория — клиенты курсов, ученики и потенциальные ученики.

## 📋 Структура сайта

### 1. НАВИГАЦИЯ (Header)
- **Sticky** позиция сверху
- Логотип `MaDE` (бордовый цвет, letter-spacing: 3px)
- Меню навигации: Главная, Ателье, Обучение, Магазин, Галерея, О MaDE, Отзывы
- Hover-эффект: подчеркивание с бордовым цветом
- Backdrop blur для современного вида

### 2. HERO-СЕКЦИЯ (Главная)
**Содержание:**
- Подзаголовок "Добро пожаловать" (uppercase, 13px, бордовый)
- Крупный заголовок (64px) с выделением span текста
- Описание (18px, max-width: 480px)
- 2 CTA-кнопки: основная и outline
- Статистика: 500+ выпускников, 10+ лет опыта, 8 курсов
- Визуальное изображение/плейсхолдер (550px height)

**Стиль:**
- Grid layout (1.2fr 1fr)
- Фоновый декоративный круг (radial gradient, rgba(157, 107, 97, 0.08))
- Текст с подсветкой на span элементах

### 3. ПРЕИМУЩЕСТВА
**Структура:**
- Секция с градиентным фоном

## 🎬 Интерактивные элементы

### Кнопки (CTA)
```
.cta-button {
  background: var(--accent)
  color: white
  padding: 18px 48px
  border-radius: 14px
  transition: 0.4s cubic-bezier(0.34, 1.56, 0.64, 1)
  hover: translateY(-2px), shadow
}

.cta-button-outline {
  background: transparent
  color: var(--accent)
  hover: background var(--accent), color white
}
```

### Hover-эффекты
- **Карточки:** translateY(-4px to -12px), border меняется, shadow
- **Галерея:** scale(1.03), overlay
- **Навигация:** подчеркивание с animation
- **Футер ссылки:** color меняется, line появляется слева с padding-left

### Анимации
- **Scroll animations:** fade-in up при скролле к элементам
- **Transitions:** 0.3s-0.4s ease/cubic-bezier для плавности
- **Button hover:** shimmer effect с ::before элементом

### JavaScript функциональность
- Smooth scroll для якорных ссылок
- Intersection Observer для анимаций при скролле
- Интерактивные фильтры галереи (active state)

## 📱 Адаптивность

### Breakpoints
- **Desktop:** полная сетка
- **Tablet (1200px):** 
  - Hero: 1 колонка
  - Courses: 6 колонок в grid (первый 6 span, остальные 3)
  - Gallery: 6 колонок (все элементы 2 span)
  
- **Mobile (768px):**

## ✅ Требования к разработке

При работе над сайтом учитывай:

1. **Performance**
   - Минимизировать CSS/JS
   - Lazy loading изображений (если будут реальные)
   - Оптимизировать анимации (использовать transform, opacity)

2. **SEO**
   - Семантический HTML
   - Meta теги
   - Структурированные данные (schema.org)
   - Alt текст на изображения

3. **Доступность**
   - Контраст текста (WCAG AA)
   - Клавиатурная навигация
   - ARIA labels где нужно
   - Focus states

4. **Масштабируемость**
   - Легко добавлять новые курсы/товары
   - CMS-friendly структура
   - Переиспользуемые компоненты
   - CSS переменные для всех цветов

5. **Форматирование кода**
   - Semantic HTML5
   - BEM или подобная методология для CSS
   - Понятные class names
   - Комментарии для больших секций
